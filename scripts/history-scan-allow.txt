# Objects `./scripts/history-scan.sh` matches, that somebody has read and cleared.
#
# One blob per line: `<40-hex object name>  <why it is not a secret>`. Keyed on the object name because
# an object name *is* its content — an entry can wave through the exact bytes that were read and
# nothing else, and editing the file gives it a new name that is scanned again from scratch.
#
# Checked in both directions, the `coverage-exempt.txt` rule: an entry matching no object in any of the
# sixteen fails the run. A cleared blob that has since been rewritten out of history is a line to
# delete, not a line to leave lying around.
#
# Dangling objects are NOT listed here and must not be added. They are reachable from no branch and no
# tag, so no push and no clone carries them; the script prints them and does not fail on them, and the
# next `git gc` takes them away — an entry for one goes stale by design.
